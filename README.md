# Revivva ERP

Sistema ERP desenvolvido para gestão de vendas, estoque, cobranças, financeiro e comissão da empresa do Luís Carlos.

## Objetivo

Modernizar o processo da empresa, eliminando fichas em papel e centralizando:

- Cadastro de clientes
- Controle de estoque
- Controle financeiro
- Cobranças
- Vendas
- Comissões
- Dashboard
